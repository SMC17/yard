# Contributing

This is an operator-maintained project. Pull requests welcome with the
following discipline:

- One change per PR. Small, reviewable, with a clear motivation in the
  description.
- Tests must pass. CI is the floor, not the ceiling.
- Match the existing code style. No mass reformatting in unrelated PRs.
- If introducing a new dependency, justify it: smaller is better.
- Documentation changes welcome at any time.

## AI codegen

External contributors must not submit AI-authored patches, issues,
commit messages, or comments. The maintainer reserves the right to use
AI codegen internally on their own substrate. That is a separate
decision and is not transitive. If your patch is AI-assisted, do not
open the PR. Hand-author it first.
